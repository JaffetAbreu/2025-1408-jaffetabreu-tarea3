# Conversor de Unidades - JavaFX

Aplicación desarrollada en JavaFX que permite convertir unidades de:

- Longitud: metros, centímetros, pulgadas, pies, yardas
- Peso: kilogramos, gramos, libras, onzas
- Temperatura: Celsius, Fahrenheit, Kelvin

## Características

- Interfaz gráfica con JavaFX
- Validación de datos (solo números, sin unidades iguales)
- Historial de últimas 10 conversiones
- Diseño basado en demo de Calculadora

## Estructura

- `Main.java`: lanza la aplicación
- `Controller.java`: lógica del controlador
- `layout.fxml`: interfaz gráfica
- `README.md`: documentación
